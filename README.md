# Hotel-Reservation-System

## 📌 Description
A console-based Hotel Reservation System developed using Core Java. This project allows users to manage hotel room bookings, cancellations, and customer records efficiently. It uses JDBC for database connectivity and demonstrates real-world application of Java concepts.

## 🚀 Features
- Room booking system
- Reservation cancellation
- Customer details management
- Cutomer details updation
- Menu-driven console interface


## 🛠️ Technologies Used
- Core Java
- JDBC (Java Database Connectivity)
- Exception Handling
- Multithreading (basic usage)

## 🧠 Concepts Covered
- Database Connectivity using JDBC
- Exception Handling
- Multithreading
- Structured Programming
